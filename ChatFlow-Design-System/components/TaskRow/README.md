# TaskRow

Linha da lista de tarefas: título com pílula de status e prioridade, metadados (Para, Prazo) e uma ação à direita. A barra lateral leva a cor da prioridade (cinza quando não há).

- Ação segue o status: Pendente = Iniciar (neutral), Em andamento = Concluir (primary), Concluída = Arquivar (secondary).
- Responsável vazio mostra travessão longo como no app; prazo sempre dd/mm/aaaa.
