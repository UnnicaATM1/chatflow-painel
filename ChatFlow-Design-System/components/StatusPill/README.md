# StatusPill

Pílula preenchida que diz em que pé está uma tarefa ou chamado. Usa as mesmas cores das colunas do quadro, então quem olha a lista reconhece o quadro.

- Status de trabalho: Pendente, Em andamento, Para aprovar, Concluída.
- Status de evento comercial usa StatusLegend, não esta pílula.
