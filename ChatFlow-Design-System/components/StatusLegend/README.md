# StatusLegend

Legenda e filtro dos sete status de evento (Confirmado, Realizado, Pendente, Em negociação, Cancelado, No-show, Interno), com ponto colorido e contagem do mês.

- Itens ativos ganham contorno e fundo na cor do status; inativos ficam neutros.
- As cores `status-*` são só para eventos. Tarefa, assunto e chamado usam StatusPill.
