# IssueCard

Cartão de assunto no quadro: título, linha de etiquetas e ações alinhadas à direita. Barra lateral ciano marca que o cartão é acionável.

- Ações mudam com a coluna: Pendente = Iniciar/Descartar/Editar; Em andamento = Concluir/Editar; Para aprovar = Encerrar/Editar; Encerrado = Arquivar/Editar (sem primário).
- Título em uma frase, sem ponto final, até duas linhas.
